# V2 — 실험용 서버 소스 패치 (프로덕션 적용 금지)

이 구성은 제공된 `server.mjs`의 특정 코드와 정확히 일치할 때만 변경하는 **소스 패치 프로토타입**입니다. 공식 패키지 로더에 통합되지 않았고 실제 서버 실행 테스트를 통과하지 않았습니다.

## 실행 (오프라인 파일 생성 전용)

```bash
python3 patch.py /path/to/server.mjs --output /tmp/gacha-forge-patched.mjs
node --check /tmp/gacha-forge-patched.mjs
```

이 명령은 운영 중인 서버에 패치를 적용하지 않습니다. DB 백업과 별도 테스트 인스턴스에서 검증 전에는 원본 파일을 교체하면 안 됩니다.

## 구현 시도

- 새 배너 생성 시 기본 주기를 3일로 변경
- 캐릭터·무기 5성 천장 분리
- 픽업 5성 확정 옵션
- 풀돌 중복 캐릭터 Glimmer 지급량 변경
- 기존 Glimmer 차감으로 캐릭터 교환하는 시험 API

## 미완료 / 위험

- **시험 교환 API는 캐릭터의 해당 월드 소속·구매 권한을 검증하지 않습니다. 운영 서버에 절대 설치하지 마세요.**
- 정가 상점 UI와 구매 가능 목록, 이벤트 일정 연동 미구현
- 자동 로테이션 트리거 및 천장 이월의 종단 간 검증 미완료
- 공식 확장 설치 ZIP, 버전별 호환·데이터 마이그레이션 및 실환경 테스트 미완료

신규 재화를 만들지 않고 기존 Glimmer를 사용합니다.
