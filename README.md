# Gacha Forge Customizer

가챠포지용 **단일 통합 커스터마이저** (비공식, 개발 중).

> **현재 게임 규칙을 변경하는 기능은 아직 구현되지 않았습니다.** 설정 UI만 사용할 수 있으며, 운영 서버에 실험용 서버 패치를 적용하면 안 됩니다.

## 최종 목표: 확장에서 즉시 서버 반영

설치 구성은 개인 확장 1개 + 가챠포지 전용 서버 패치 1개이며 **하나의 제품**으로 관리합니다.

1. 마리나라 가챠포지 화면에서 커스터마이저 설정을 변경합니다.
2. 개인 확장이 인증된 서버 전용 설정 API로 변경값을 전송합니다.
3. 서버가 권한과 범위를 검증하고 원자적으로 영구 저장합니다.
4. 서버의 실제 배너·뽑기·상점 판정이 저장된 값을 읽어 사용합니다.
5. 서버가 확정한 값을 UI에 다시 표시합니다. 폰과 PC도 같은 서버 값을 읽습니다.

**서버 파일을 설정 변경 때마다 직접 덮어쓰지 않습니다.** 설정 업데이트 때 엔진 재시작 없이 반영하는 것을 목표로 합니다. 서버 패치 자체의 최초 설치와 업데이트에는 재시작이 필요할 수 있습니다.

## 목표 기능

- 픽업 배너 주기 조절 및 자동 로테이션
- 캐릭터/무기 별도 천장, 픽업 확정·천장 이월
- 4성·5성 풀돌 중복 Glimmer 보상 조절
- 기존 Glimmer를 사용한 캐릭터 정가 상점 (신규 재화 없음)
- 월드별 설정, 서버 영구 저장 및 기기간 동기화

## 현재 파일 구성

- `manifest.json`, `extension.js`: 단일 통합 개인 확장 진입점. **현재는 로컬 설정 UI만 동작**합니다.
- `experimental/server-patch/`: 이전의 **미검증·위험한 프로토타입**. 월드 소속과 구매 권한 검증이 누락되어 있어 절대로 운영 서버에 적용하면 안 됩니다.

## 현재 동작 확인

저장소 루트의 `manifest.json`과 `extension.js`를 ZIP 최상위에 두어 설치합니다. 이전 V1 확장과 동시에 활성화하지 않습니다.

현 단계에서 설정은 서버로 전송되지 않으며, 게임 내 가챠 판정·재화·상점과 연동되지 않습니다.
