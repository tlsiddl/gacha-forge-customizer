# Gacha Forge Customizer

Gacha Forge용 **단일 통합 커스터마이저** 개발 프로젝트 (비공식).

> **개발 중 / 실제 가챠 규칙 변경 미구현.** 현재 마리나라 개인 확장 화면에는 설정값만 저장되며 배너 기간, 천장, 확정 픽업, 정가 구매는 아직 실제 게임에 적용되지 않습니다.

## 구조

- `manifest.json` + `extension.js` : 통합 마리나라 개인 확장 진입점 (현재 설정 UI와 브라우저 로컬 저장 지원)
- `v2-server-patch/` : **운영 서버 적용 금지**인 이전 서버 소스 패치 실험 코드. 실제 구매 권한 검증 및 데이터 안전장치가 미완료입니다.
- `v1-standalone/` : 구버전 참고 자료. 신규 설치에는 사용하지 않습니다.

## 목표 기능

1. 픽업 배너 주기 단축과 다음 픽업 자동 생성
2. 캐릭터 / 무기 천장 개별 설정 및 픽업 확정 상태 이월
3. 4성·5성 풀돌 중복 보상 조절
4. **기존 Glimmer**로 4성·5성 캐릭터 정가 교환 (신규 재화 없음)
5. 가챠포지 화면에 통합된 설정창에서 변경 사항 관리

서버에서 판정해야 하는 기능은 안전한 서버 연동이 구현되고 검증될 때만 활성화합니다.

## 현재 테스트 방법

저장소 루트의 `manifest.json`, `extension.js` 두 파일을 ZIP 최상위에 압축해 개인 확장 관리 화면에 설치합니다. 구 V1과 동시 설치하지 않습니다.

**현재 확인 가능한 것**: 가챠 설정 버튼, 숫자 설정, 로컬 저장, JSON 복사.

**현재 불가능한 것**: 실 배너 교체, 천장 판정 수정, Glimmer 상점 구매.

실서비스에서 `v2-server-patch/patch.py`를 실행하거나 적용하지 마세요. 구매 자격 검증과 월드 식별 및 중복 요청 방지가 구현되지 않았습니다.
