# Gacha Forge Customizer

Gacha Forge의 배너 주기, 천장, 픽업 확정, Glimmer 중복 보상 및 캐릭터 정가 교환 기능을 연구하는 비공식 커스터마이저 프로젝트입니다.

> **개발 중(WIP) — 현재 배포 파일은 실제 마리나라에 설치할 수 있는 완성 확장이 아닙니다.**

## 구성

- **V1 / standalone**: 서버 수정 없이 열어볼 수 있는 HTML 설정 시안입니다. 게임 데이터와 연결되지 않으며 가챠 결과를 변경하지 않습니다.
- **V2 / server-patch**: 서버 소스에 대한 엄격 일치 오프라인 패치 프로토타입입니다. 실제 서비스 적용을 금지합니다.

## 목표

- 배너 로테이션 주기 조절 및 신규 픽업 자동 교체
- 캐릭터와 무기의 개별 천장, 픽업 확정, 천장 이월
- 풀돌 중복 획득 시 기존 **Glimmer** 지급량 조절
- 기존 Glimmer로 4성/5성 캐릭터를 구매하는 정가 상점

**신규 재화를 도입하지 않습니다.** 기존 Glimmer 잔액과 원래 상점 기능을 보존하는 방향으로 개발합니다.

## 현재 제한사항

V1의 설정값은 게임에 적용되지 않습니다. V2의 시험용 교환 엔드포인트는 캐릭터의 월드 소속과 구매 권한을 검증하지 않으므로 운영 서버에서 실행해서는 안 됩니다. 정가 상점 UI, 자동 로테이션 트리거, 이벤트 일정 연동, 데이터 마이그레이션 및 종단 간 테스트는 미완료 상태입니다.

현재 제공된 소스는 연구/검토 목적이며, 실제 서버 적용 전 별도 테스트 인스턴스와 데이터 백업이 필요합니다.
